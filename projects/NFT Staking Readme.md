NFT Staking ETH Mining Contract
This smart contract enables users to stake NFTs to earn ETH rewards. It supports single & batch stake/unstake operations, strictly follows the CEI security execution mode, and is equipped with reentrancy protection, contract pause function, reward pool health monitoring, and a risk control system of 7-day timelock emergency withdrawal for administrators.
Core Features
Security Architecture: CEI execution sequence + ReentrancyGuard to defend against cross-function reentrancy attacks
Gas Optimization: Combined loop logic for batch unstaking to reduce traversal times and gas consumption
Risk Control Mechanism: Contract pause fuse switch, reward pool balance warning line, 7-day timelock for emergency withdrawal
Batch Limit Control: Maximum 100 NFTs per single batch to prevent transaction failure caused by block gas limit overflow
Complete On-chain Events: Staking, unstaking, reward claiming, reward pool funding and administrator operations all generate on-chain logs for traceable audit

Core Contract Interfaces
User Interfaces
stake(tokenId): Stake a single NFT
stakeBatch(tokenIds[]): Batch stake multiple NFTs
unstake(tokenId): Unstake single NFT and settle corresponding rewards
unstakeBatch(tokenIds[]): Batch unstake and settle rewards uniformly
claimReward(tokenId): Claim rewards of single NFT without unstaking
claimAllRewards(): Claim rewards generated by all NFTs staked by the current user at once
estimateAllRewards(user): Query estimated total pending rewards of a specified user
Administrator Permission Interfaces
setRewardRate(): Modify daily ETH output per single NFT
setPaused(): Pause / resume all business functions of the contract
setMinRewardPoolBalance(): Modify the minimum safe warning balance of the reward pool
requestEmergencyWithdraw(): Submit application for emergency withdrawal of funds in reward pool
cancelEmergencyWithdraw(): Revoke an unexpired withdrawal application
executeEmergencyWithdraw(): Execute withdrawal after the 7-day timelock expires
Security Description
All transfer interactions are executed after state modification, complying strictly with the CEI security principle.
All external business functions are equipped with a global nonReentrant lock, preventing attackers from calling staking interfaces inside the NFT receiving callback function to implement cross-function reentrancy.
NFTs will be returned to users uniformly after all staking status changes are completed, eliminating intermediate exploitable states.
If reward transfer fails, the entire transaction will roll back, and the last claim time will not be updated in advance, avoiding risks of reward loss and duplicate issuance.

合约核心接口
用户可用接口
stake(tokenId)：质押单个 NFT
stakeBatch(tokenIds[])：批量质押多枚 NFT
unstake(tokenId)：解质押单个 NFT 并结算对应奖励
unstakeBatch(tokenIds[])：批量解质押并统一结算奖励
claimReward(tokenId)：不解质押，单独领取单枚 NFT 奖励
claimAllRewards()：一次性领取本人所有质押 NFT 产生的奖励
estimateAllRewards(user)：查询某用户预估待结算总奖励
管理员权限接口
setRewardRate()：修改单个 NFT 每日挖矿产出 ETH 数额
setPaused()：暂停 / 恢复合约全部业务功能
setMinRewardPoolBalance()：修改奖励池最低安全预警余额
requestEmergencyWithdraw()：提交奖励池紧急提现申请
cancelEmergencyWithdraw()：撤销未到期的提现申请
executeEmergencyWithdraw()：7 天时间锁结束后执行提现操作
安全说明
所有转账交互统一放在状态修改完成之后，严格遵守 CEI 安全原则
全部业务外部函数挂载nonReentrant全局锁，杜绝攻击者在 NFT 接收回调函数内调用质押接口实现跨函数重入
所有质押状态变更完毕后，再统一返还 NFT 给用户，不存在可被攻击的中间状态
奖励转账失败则整笔交易回滚，不会提前更新领奖时间，杜绝奖励丢失、重复发放漏洞
